# AI Internship Applier

An AI-powered internship application automation workflow built using n8n, Google Gemini, Google Sheets, and Gmail.

## Project Overview

This project automates internship application preparation by processing internship opportunities from Google Sheets and generating personalized application emails using AI.

## Technologies Used

- n8n
- Google Gemini
- Google Sheets
- Gmail
- LLM Chain
- Structured Output Parser

##  Workflow

1. Google Sheets Trigger detects internship entries.
2. Basic LLM Chain processes internship information.
3. Google Gemini generates personalized email content.
4. Structured Output Parser formats the AI response.
5. Gmail sends the generated application email.

## Key Features

- Automated internship data processing.
- AI-generated personalized application emails.
- Structured AI responses.
- Gmail integration.
- Workflow automation using n8n.

## Setup

1. Download the workflow JSON file.
2. Import it into your n8n workspace.
3. Configure Google Sheets, Google Gemini, and Gmail credentials.
4. Connect your spreadsheet.
5. Execute the workflow.
